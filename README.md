## Overview

`WEBPROG-IT252` serves as a central workspace for hands-on web development projects. It covers foundational frontend skills alongside component-driven UI development, state management, and modern tooling.

## Tech Stack

- **HTML5 & CSS3**: Semantic document structure, custom styling, and responsive layout design
- **JavaScript (ES6+)**: Interactive logic, state updates, and modern module syntax
- **React & Vite**: Component-based UI architecture with fast local development and bundling

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/BluPizarra/WEBPROG-IT252.git
   ```
2. Navigate into a project folder (for example, `react-demo`):
   ```bash
   cd WEBPROG-IT252/react-demo
   ```
3. Install dependencies (if needed) and start the development server:
   ```bash
   npm install
   npm run dev
   ```
