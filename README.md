## Overview

This repository serves as a workspace for web programming projects focused on building interactive, responsive interfaces with vanilla HTML, CSS, JavaScript, and React. Each project explores practical frontend concepts such as semantic markup, CSS layout systems, DOM manipulation, component-based UI, state management, and client-side validation.

## Projects

| Project | Location | Description |
| --- | --- | --- |
| Mini Expense Tracker | `index.html`, `script.js` | A responsive single-page expense tracker with category filtering, inline form validation, XSS-safe rendering, and live total calculation. |
| React Demo | `react-demo/` | A starter React 19 + Vite application demonstrating component rendering, `useState` counter state, and Hot Module Replacement (HMR). |

## Tech Stack

- **HTML5**: Semantic structure and accessible form controls
- **CSS3**: Custom properties, Flexbox, Grid, and responsive media queries
- **JavaScript**: Client-side state management, event delegation, and dynamic DOM updates
- **React & Vite**: Component-based UI development with fast dev server bundling

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/BluPizarra/WEBPROG-IT252.git
   ```
2. Navigate into the repository folder:
   ```bash
   cd WEBPROG-IT252
   ```
3. **Static Projects**: Open `index.html` directly in any modern web browser.
4. **React Demo**:
   ```bash
   cd react-demo
   npm install
   npm run dev
   ```
